Transitions statt Keyframes für Toasts

Schnell mehrmals klicken. Jeder Toast zielt mitten in der Bewegung neu, statt von vorn zu starten. Mit der Maus über den Stapel fächert er auf, und die Timer pausieren.

Asymmetrie

Langsam, wo du entscheidest. Schnell, wo das System antwortet

Halten füllt den Button über 2s linear. Loslassen springt in 200ms zurück. Umgesetzt mit clip-path: inset().

Ein schneller Wisch reicht

Das Sheet schließt ab 40 % Strecke oder ab einer Geschwindigkeit von 0,11 px/ms. Nach oben gibt es Widerstand statt einer harten Wand.

Tooltips

Erst warten, danach sofort

Der erste Tooltip wartet 500ms gegen versehentliches Auslösen. Gleitest du weiter, erscheinen die Nachbarn ohne Verzögerung und ohne Animation.

.tooltip[data-instant] { transition-duration: 0ms }
Stagger

Kaskade statt Block

50ms Versatz pro Eintrag. Kurz genug, dass nichts wartet, lang genug, dass das Auge der Liste folgt.

Häufigkeit

Tastatur-Aktionen werden nie animiert

Eine Befehlspalette öffnest du hundertmal am Tag. Jede Animation würde sich wie Verzögerung anfühlen. Darum erscheint sie hier ohne Übergang.

So reviewt der Skill Code

Der Skill schreibt für Reviews eine Tabelle mit Vorher, Nachher und Begründung vor. Hier angewendet auf typisches CSS, wie es ein Agent ohne Geschmack schreibt.

/* Typischer Standard-Output */
.dropdown { transition: all 300ms ease-in; transform-origin: center; }
.dropdown[data-state="closed"] { transform: scale(0); }
.card:hover { transform: scale(1.05); }
.toast { animation: slideIn 500ms; }
.cmdk { animation: pop 250ms ease-out; }
.button { cursor: pointer; } /* kein :active */
